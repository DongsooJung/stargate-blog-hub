문제 1

72026의 일의 자리 숫자는?

힌트 보기

7, 7², 7³, 7⁴, …의 일의 자리를 반복될 때까지 적어 보세요.

풀이 보기

7의 거듭제곱의 일의 자리는 7, 9, 3, 1, 다시 7입니다. 74 = 2401의 일의 자리가 1이므로 74을 곱해도 일의 자리가 바뀌지 않아 주기는 4입니다.

2026 = 4 × 506 + 2이므로 72026의 일의 자리는 72 = 49와 같습니다. 답: 9

문제 2

5로 나누면 나머지가 2, 7로 나누면 나머지가 3인 가장 작은 양의 정수는?

힌트 보기

7로 나눈 나머지가 3인 수를 나열하고 5로 나눈 나머지를 확인하세요.

풀이 보기

7로 나눈 나머지가 3인 수는 3, 10, 17, 24, …(3 + 7t)이고, 5로 나눈 나머지는 3, 0, 2, …입니다. 처음으로 2가 되는 수가 17이며 더 작은 후보는 없습니다.

검산: 17 = 5·3 + 2 = 7·2 + 3. 답: 17. 다른 해는 17에 lcm(5, 7) = 35의 배수를 더한 17, 52, 87, …입니다.

문제 3

완전제곱수를 4로 나눈 나머지는 2가 될 수 없음을 증명하세요.

힌트 보기

제곱하는 수가 짝수인 경우와 홀수인 경우로 나누세요.

풀이 보기

k = 2m이면 k² = 4m²이므로 나머지 0입니다. k = 2m + 1이면 k² = 4m(m + 1) + 1이므로 나머지 1입니다.

모든 제곱수는 4로 나눈 나머지가 0 또는 1이므로 2(와 3)는 불가능합니다. ∎
