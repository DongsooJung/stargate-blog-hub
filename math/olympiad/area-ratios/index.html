넓이의 비 — 자 없이 그림 읽기

세 문제 모두 한 가지 사실로 풀립니다: 높이가 같은 삼각형의 넓이 비는 밑변의 비와 같다.

English version on Stargate Learn →

이렇게 풀어 보세요 — 10분 타이머를 맞추고 각 문제의 답과 이유를 적으세요. 막힐 때만 힌트를, 답을 낸 뒤에만 풀이를 여세요. 이유 없는 정답은 절반짜리 답입니다.

문제 1

삼각형 ABC에서 M이 BC의 중점일 때, 중선 AM이 삼각형을 넓이가 같은 두 삼각형으로 나눔을 증명하세요.

힌트 보기

삼각형 ABM과 AMC는 A에서 BC까지의 높이를 공유합니다.

풀이 보기

A에서 BC까지의 높이를 h라 하면 [ABM] = ½·BM·h, [AMC] = ½·MC·h입니다. M이 중점이므로 BM = MC이고 두 넓이는 같습니다. ∎

문제 2

점 D, E가 BC를 B, D, E, C 순서로 삼등분합니다. [ABC] = 45일 때 [ADE]를 구하세요.

힌트 보기

밑변 DE와 BC를 비교하세요.

풀이 보기

ADE와 ABC는 A에서의 높이가 같고 DE = BC/3이므로 [ADE] = [ABC]/3 = 15입니다.

문제 3

D는 AB 위에 AD : DB = 1 : 2, E는 AC 위에 AE : EC = 2 : 1이 되도록 있습니다. [ABC] = 54일 때 [ADE]를 구하세요.

힌트 보기

삼각형 ABE를 거쳐 두 단계로 가세요.

풀이 보기

ABE와 ABC는 꼭짓점 B를 공유하고 밑변 AE, AC가 한 직선 위에 있으므로 [ABE] = (2/3)·54 = 36입니다.

ADE와 ABE는 꼭짓점 E를 공유하고 밑변 AD, AB가 한 직선 위에 있으므로 [ADE] = (1/3)·36 = 12입니다.

변형 문제

문제 3에서 사각형 BDEC의 넓이는? (답: 54 − 12 = 42)
